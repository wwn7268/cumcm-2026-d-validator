# D题学生附件验证器

**v1.1.0 · 离线桌面程序**

供教师和学生检查 D 题第二、三、四问的 Excel / CSV 附件。程序重建完整用频计划，判断可行性、定位规则错误和时频冲突，并绘制占用矩阵。

文件在本机读取，学生原件不被修改，数据不上传。**“可行”表示满足所选时间窗和本程序建模口径下的约束，不代表最优。**

## 下载和启动

1. 在本仓库页面选择 **Code → Download ZIP**，将 ZIP 完整解压。不要直接从压缩包中运行。
2. 准备 **Python 3.10 或以上**，以及 Tkinter 图形组件。Windows 的标准 Python 安装程序可提供 Tkinter；安装时勾选将 Python 加入 PATH。
3. 在解压目录打开终端，安装 Python 依赖：

   ```powershell
   python -m pip install -r requirements.txt
   ```

4. Windows 双击 **启动验证器.cmd**。也可在本目录运行：

   ```powershell
   python app.py
   ```

GitHub 用于发布源码和下载文件，**不能直接在 GitHub 网页中运行此桌面程序**。源码包不包含 Python 运行环境，依赖准备好后，验证和导出均可离线完成。目前图形界面已在 Windows 上测试；其他系统需自行提供 Tkinter 和可用中文字体。

## 如何验证

| 问题 | 学生提交附件 | 基准方案 |
| --- | --- | --- |
| 第二问 | `result2.xlsx` | 随程序提供的原始150台装备计划 |
| 第三问 | `result3.xlsx` | **必须同时选择该学生采用的 `result2.xlsx`** |
| 第四问 | `result4.xlsx` | 原始150台装备计划；无需第二问附件 |

1. 选择问题编号和附件，必要时选择工作表。
2. 核对时间上限 **H**，点击 **开始验证**。
3. 在“判定与统计”查看结论和指标，在“问题与冲突”查看错误行及冲突位置，在“时频矩阵”查看图示。
4. 双击冲突记录可定位到矩阵对应区域；工具栏支持缩放、平移和恢复全图。
5. 点击 **导出报告**，生成 PNG 图、Excel 明细、占用计数 CSV、JSON 结果和文字摘要。

默认 **H=643**，取原计划最晚结束时刻。这是本程序采用的时间窗假设，并非题目明确规定的截止时间；可改为整数1～10000，应与学生论文的假设一致。第三问按**固定第二问布局**检查，若学生采用联合重排等不同模型，应先核对口径。

第一次使用可以点击 **载入可行示例**。七份可行与错误示例及其预期结果见 [examples/说明.md](examples/说明.md)。第二、三问的示例必须配套使用。

## 附件格式与规则

使用题目官方表头，支持 `.xlsx`、`.xlsm`、`.csv`。第二、四问仅列调整或撤销的装备，未列出的装备保持原计划；第三问仅列新增C类装备。区间写成 `[下界,上界)`，端点必须为整数。公式单元格、旧版 `.xls` 不受支持。

- **第二问：** 调频不超过10Δf，调时不超过5Δt；每台只能调整一个参数或撤销。
- **第三问：** 先验证对应第二问方案，再检查新增C类的全部12次使用；新增装备与基础方案及彼此之间均不得冲突。
- **第四问：** 在第二问规则上，仅C类可改间隔，变化幅度不超过10Δt且新间隔非负；调频、调时、改间隔仍至多选择一项，或者撤销。
- **全部问题：** 保持规定频宽、单次时长和使用次数，展开所有重复使用，检查频率 `[0,100)` 和时间 `[0,H)` 边界。半开区间仅接触边界不算冲突。

矩阵以红色标记冲突。面积利用率按**占用区域的并集面积 / (100H)**计算，间隔不计占用，有冲突的格不重复计面积。完整表头、约束解释和统计口径见 [使用说明.md](使用说明.md)。

## 命令行使用

在本目录运行：

```powershell
python -X utf8 validate.py 2 "examples/result2_可行示例.xlsx"
python -X utf8 validate.py 3 "examples/result3_可行示例.xlsx" --base-q2 "examples/result2_可行示例.xlsx"
python -X utf8 validate.py 4 "examples/result4_可行示例.xlsx"
```

可选参数：`--horizon 643`、`--sheet Sheet1`、`--base-sheet Sheet1`、`--output 输出目录`。默认报告存入 `results/` 下的新子目录；退出码0为可行、1为不可行、2为输入错误或校验未完成。

## 程序结构

| 文件/目录 | 用途 |
| --- | --- |
| `app.py` | Tkinter桌面界面 |
| `engine.py` | 读表、重建计划与独立规则验证 |
| `visuals.py` | 时频矩阵与图形 |
| `reporting.py` | 统计摘要及报告导出 |
| `validate.py` | 命令行入口 |
| `data/original_plans.json` | 附件1整理的150条原始计划 |
| `examples/` | 七份演示附件及预期结果 |
| `tests/` | 规则与界面回归测试 |

## 数据来源

`data/original_plans.json` 来自题目附件1，包含A类20台、B类40台、C类90台的参数，用于验证器重建基准计划。`examples/` 是依据这些参数生成的演示方案，不能据其数量推断学生解答的最优性。本仓库未附原题PDF或学生作业，题目及其原始附件的权利归原权利人所有。
