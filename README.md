# 2026年高教社杯数学建模竞赛D题 · 解答验证器

把同一套方案的四份结果放在一个文件夹里，程序会分别给出第一至四问的验证结果。第一问核对冲突装备对是否报全，第二至四问检查方案在所选时间窗内是否可行。

**[下载验证器 v1.4.1（ZIP）](https://github.com/wwn7268/cumcm-2026-d-validator/releases/download/v1.4.1/cumcm-2026-d-validator-v1.4.1.zip)**

## 安装和启动（Windows）

1. 安装 Python 3.10 或更高版本，安装时勾选 **Add python.exe to PATH**，保留 Tkinter 图形组件。
2. 完整解压下载的 ZIP，打开能看到 `启动验证器.cmd` 和 `requirements.txt` 的文件夹。
3. 首次使用时，在这个文件夹的地址栏输入 `powershell`，按回车，再运行下面的命令。

   ```powershell
   python -m pip install -r requirements.txt
   ```

4. 双击 **启动验证器.cmd**。以后直接双击即可。

想先试一下，可以点 **载入四问示例**，再点 **开始验证**。自带示例的四问应全部显示“验证通过”。

## 验证自己的结果

按题目模板填写附件，推荐使用下面的文件名。程序也支持 `.xlsm` 和 `.csv`。

| 文件名 | 填写内容 |
| --- | --- |
| `results1.xlsx` | 原始计划中发生冲突的装备对 |
| `results2.xlsx` | 第二问调整或撤销的装备 |
| `results3.xlsx` | 在这份第二问方案上新增的 C 类装备 |
| `results4.xlsx` | 第四问允许修改 C 类间隔后的调整与撤销方案 |

1. 把四份附件放在同一个文件夹，点 **选择目录…** 选中它。也可以选上一级目录，程序会查找子目录。如果找到多套结果，直接选中要检查的那一套。
2. 核对第二至四问的时间窗。默认值为 **H = 643**，如果论文采用了其他截止时刻，在这里改成对应的值。
3. 点 **开始验证**，在四张结果卡上查看各问是否通过。若提示“缺少结果”，检查对应文件的名称和位置。第三问依赖同一套方案的第二问结果，第二问验证通过后才能检查新增装备。

![四问验证通过后的界面，每张卡片对应一问，可点击查看详情](docs/images/08_四问目录验证通过.png)

## 查错和导出

点卡片下方的详情按钮，例如 **查看问题 2 详情**。第一问可以查到具体漏报或多报的装备对。第二至四问可以查看撤销数、调整数、总平移距离以及 A、B、C 各类的分项，第三问还会列出新增装备数。通过表示方案满足当前设置下的可行性检查，最优性需要另行论证。

若提示时频冲突，打开 **问题与冲突**，可以看到哪两台装备、第几次使用重叠，以及重叠的时间和频段。双击该条记录即可在矩阵中定位。改好附件后，再点 **开始验证**。

点 **导出四问报告…** 并选择保存位置，即可保存四问汇总，以及已完成检查各问的 Excel 明细和时频矩阵图。
