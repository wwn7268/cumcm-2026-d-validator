# 四问目录验证示例

在验证器中选择下面某一个以 01～05 开头的目录，时间窗保持 H=643，再点 **开始验证**。

| 选择的目录 | 放了什么 | 应看到什么 |
|---|---|---|
| `01_子目录内四问齐全` | 四份附件都在里面的“方案附件”子目录 | 自动找到这套附件，四问全部通过 |
| `02_缺少第一问` | 只有第二、三、四问 | 第一问显示“缺少结果”，其余三问通过 |
| `03_第一问漏报一对` | 四问齐全，第一问删去了 C076 与 C086 这一对 | 第一问失败并指出漏报；其余三问通过 |
| `04_多个完整子目录` | “方案A”“方案B”各有一整套四问附件 | 提示目录不唯一，不自动选择；直接选其中一个子目录即可验证 |
| `05_子目录仍缺少全部结果` | 根目录和子目录都只有说明文件，没有结果附件 | 四问均显示“缺少结果” |

不要选外层“四问目录测试示例”后期待全部通过：这里同时放着多套附件，本来就应提示需要明确选择。

各套附件来自同一份内置方案。第二问撤销 6 台、调整 126 台，第三问新增 136 台，第四问撤销 4 台、调整 140 台。正确的第一问列出 297 对装备；漏报示例只有 296 对。

原始计划的 431 次交叠事件属于第一问要找出的冲突。第一问通过只表示冲突对报告正确，不表示原始计划没有冲突。

这五类示例已实际运行，结果见[测试结果](测试结果.md)。

也可以在程序目录运行：

```powershell
python -X utf8 validate.py --directory "examples/四问目录测试示例/01_子目录内四问齐全"
```
