# 验证示例

第二问文件采用官方四列表头，只填写调整或撤销的装备；省略的装备保持原计划。第三问文件采用官方三列表头，只填写新增 C 类装备。第四问采用官方五列表头，增加“调整后间隔时长”列；直接与题目原始计划比较，无需第二问附件。

| 文件 | 用途与预期结果 |
| --- | --- |
| `result2_可行示例.xlsx` | 第二问可行方案：撤销 6 台、调整 126 台，总调整幅度 678；占用面积 15816。 |
| `result3_可行示例.xlsx` | 第三问新增 136 台，必须配合本目录的第二问可行示例使用；合并占用面积 25608。 |
| `result2_重复编号示例.xlsx` | 在可行方案末尾重复一行装备，应报告编号重复。 |
| `result2_频移超限示例.xlsx` | 将 A002 原频段 `[5,15)` 改为 `[16,26)`，频移为 11，应报告超过允许的 10。 |
| `result3_新增重叠示例.xlsx` | 新增第 137 台与第 1 台完全重合，应报告冲突。 |
| `result4_可行示例.xlsx` | 第四问可行方案：撤销 4 台、调整 140 台，其中调频 66 台、调时 33 台、改变间隔 41 台；占用面积 16176，冲突 0。 |
| `result4_间隔超限示例.xlsx` | 将可行方案的 C001 调整后间隔改为 19，较原间隔 8 增加 11，应报告超过允许的 10。 |

这些文件用于说明可行性检查及错误定位，不能据此判断任意提交方案是否达到最优。第三问的可行性取决于所采用的第二问完整布局，不能随意更换基准方案。

第二、三问可行示例来自项目中已有的九层优先级求解结果，由 `tests/build_examples.py` 转为官方附件格式，原结果未作改动。第四问可行示例由 `tests/build_q4_examples.py` 直接复制 `四问完整稿_PDF与LaTeX/对应结果附件/result4.xlsx`，对应旧版《D题_四问完整建模与求解.pdf》，六级指标为 `[4,0,2,140,18,34]`。
